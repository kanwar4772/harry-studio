# Harry Studio Portfolio Website

A deployable single-page portfolio website built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` – main page
- `style.css` – styling
- `script.js` – filters, animations, modals
- `assets/` – portfolio images used on the site

## How to use
1. Extract the ZIP.
2. Open `index.html` locally to preview.
3. Edit contact links in `index.html`:
   - The Fiverr URL is already set to: https://www.fiverr.com/s/xrX0YzX
4. Upload the folder to Cloudflare Pages, Netlify, GitHub Pages, or any static host.

## Notes
- The site is responsive and requires no build step.
- All project cards open detailed modal case studies.
- Replace or add more work anytime by updating image files and card data.
